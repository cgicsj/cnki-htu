# CNKI journal-browse

1. Use the visible 出版物检索/期刊导航 control from the CNKI entry or a supplied journal link. Search the exact journal name.
2. Filter the actual search-result area to 期刊 if results mix journals, books or yearbooks. A header may contain another “期刊” link to a different destination: scope the locator to the result filters. Verify identity by journal title, ISSN/CN number and publisher if displayed; do not choose the first substring match or convert the name to a guessed URL slug.
3. Read journal scope and accessible metadata, then expand the requested year before choosing an offered issue. Verify the displayed year/issue label and wait for the corresponding article list to replace the prior directory before extraction; existing rows can belong to 网络首发 or another issue.
4. If the user requests latest articles, distinguish online-first material from the most recent numbered issue.
5. Report any journal metrics with the source edition/year. Read indexing only from the journal's identity/indexing section, preserving any coverage years; a database name elsewhere in the page is not inclusion evidence. When validating a source-category filter (such as EI), compare the selected category and result count/facet with the journal's own identity/indexing section for at least one sampled result. Do not infer that every hit is indexed from the checkbox alone. Do not equate CNKI composite impact factor with JCR impact factor or infer a current core-journal classification.
6. Extract article links from the issue itself; preserve sequence and mark shortened authors. Pagination follows visible controls.
7. External editorial/publisher links are a separate destination; label them and preserve the user's access route.
