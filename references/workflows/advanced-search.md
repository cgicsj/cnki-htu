# CNKI advanced-search

1. Open the visible 高级检索 link from the authorized entry. Choose the requested database first (default 学术期刊), then inspect the current fields, Boolean and date controls. Changing database can rebuild the form and clear its values; re-observe and refill after a database change. Do not depend on an old page URL or select-element indices.
2. Translate intent into rows: topic → 主题, title → 篇名, author → 作者, institution → 作者单位, journal → 文献来源, only when those labels actually exist. If a field is unavailable, disclose that limitation instead of silently changing its meaning.
3. Connect separate concepts with AND. For the acceptance example use 主题=生成式人工智能 AND 主题=企业创新, journals only, publication date from 2023-01-01 through today's date. Preserve the user's own alternative query if provided.
4. Use the page's date controls; record whether they filter publication, online-first or year only. The same site may offer a day-level calendar in 总库 and publication-year inputs in 学术期刊. Operate readonly dates through their calendar, without removing readonly or forcing values. Confirm both final endpoints; a calendar selection alone does not prove the submitted query applied them. A year-only filter may include forthcoming issues. The results column may show an online-publication date earlier than the numbered issue's publication year; when dates appear outside the selected year, open a representative record and compare its issue year with the explicit online-publication metadata before calling it a filter failure.
5. Inspect any enabled synonym/Chinese-English expansion option; record the state and do not describe expanded search as exact matching.
6. Submit, then verify the active database, fields, AND/OR/NOT relationships, dates, expansion state and result count against the intended query. The result summary may omit publication-year and source-category filters: if so, retain the submitted form's observed values and cross-check the year/source facet and a representative record; report which parts are independently confirmed and which are not. Do not claim a filter applied solely because its checkbox was selected or because a result count looks plausible. “暂无数据，请稍后重试” is an error, not an explicit zero-results response. If a diagnostic query removes dates/fields or switches database, label it separately; its success does not validate the original query. For newest first use the navigate-pages workflow. Do not pass ScienceDirect parameters such as qs, tak or sortBy.
7. Extract the requested results using the internal parse-results workflow; read each row's exact title, URL, date, source and displayed authors. Count unique records, preserve site order, and report missing/shortened fields.
8. If fewer results than requested, report the actual number. Broaden only within the user's scope and label the new search separately.
