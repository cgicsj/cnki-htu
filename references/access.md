# 校园访问、EasyConnect 与机构认证

## 固定配置与证据

本技能采用用户指定的深信服路线：EasyConnect → `https://vpn.htu.edu.cn` → 所选本地浏览器 → `http://www-cnki-net-s.vpn.htu.edu.cn:8118`。

[学校说明](https://www.htu.edu.cn/info/2011/0116/c18431a250850/page.htm)同时列出深信服 VPN 和另一套 WEB VPN（v.htu.edu.cn）。本技能的“WebVPN”名称沿用用户称呼，不把两套入口混用。学校说明账号密码与办事大厅相同；提示用户自行输入学生账号密码，不代填猜测值。

2026-10-21 在线实测补充：

- 客户端连上后，知网相关域名在 Windows 上解析到深信服虚拟地址段（`198.18.0.0/15`），例如 `www-cnki-net-s.vpn.htu.edu.cn`、`kns-cnki-net-s.vpn.htu.edu.cn`、`docdown-cnki-net-s.vpn.htu.edu.cn`、`bar-cnki-net-s.vpn.htu.edu.cn`、`vpn.htu.edu.cn`。域名解析到该网段只说明隧道在转发，仍不代表已完成机构认证。
- 直接请求 `http://www-cnki-net-s.vpn.htu.edu.cn:8118` 会返回深信服的跳转外壳，把浏览器送到 `https://vpn.htu.edu.cn/portal?redirect_uri=...`。用不带浏览器 Cookie 的普通 HTTP 会话无法完成该认证，机构认证必须在本次所选的用户本地浏览器里核验。
- 认证成功的可观察信号是检索结果页顶部的机构名（实测为“河南师范大学图书馆”，出现在 `ecp_header_unitName` 与 `ecp_unitAccountName` 元素中）。个人登录状态与机构名是两回事，不要把“个人登录”当成机构认证。
- 校园入口按资源类型分发到不同子域；下载涉及的子域与内容拦截扩展见 [Chrome HTTP 下载与连续 PDF 下载](downloads.md)。

## 检查顺序

1. 先按[浏览器选择](browser.md)检查当前 agent 提供的浏览器能力；优先用 Codex Chrome 插件（`@Chrome`）连接本地 Chrome，插件不可用时再试 Chrome DevTools MCP 等已提供且可接入同一会话的工具。连接不可用时报告实际状态，不切换到未验证的浏览器会话。在实际连接的会话内核验认证，不复用其他会话的登录结论；安装本技能本身不安装浏览器插件或 MCP 服务。
2. Windows 可运行 `scripts/check_environment.ps1`，得到 EasyConnect 进程和安装路径信号。它明确返回 `authentication=unknown`，不是登录判断器。若本机执行策略阻止脚本，使用 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check_environment.ps1`，不要修改全局策略。如果需要打开已安装客户端，运行带 `-LaunchEasyConnect` 的命令，让用户在可见客户端中登录；程序不存在时打开学校说明页让用户下载。其他系统使用当前桌面工具查看 EasyConnect。
3. 在环境检查阶段先完成 [Chrome 不安全内容设置](downloads.md#用户选择的校园域通配例外)：核实“允许显示不安全内容”列表包含 `[*.]htu.edu.cn`，缺少时按已授权的规则添加。不要等到下载被拦截才设置。已有有效规则不重复添加；工具无法操作内部页面时，立即给用户地址和步骤，等待用户确认设置完成后再开始检索/下载。记录工具实见或用户确认的区别；不能把脚本输出当作已设置。
4. 如果桌面工具支持，读取 EasyConnect 中实际的已连接/连接成功状态及服务器；不能只看托盘图标或进程名。如果当前环境不能读取客户端状态，标记“客户端状态未核验”，继续用校园页面和机构认证核验可用访问，不能宣称检测到已登录。
5. 按校园入口逐页进入知网，不拼接代理地址或猜测新标签 URL：
   - 在所选本地浏览器打开 `https://vpn.htu.edu.cn`。若页面显示已登录并提供“打开资源界面”按钮，点击该按钮一次，然后等待新窗口或标签；此按钮可能弹出独立的新浏览器窗口，不一定替换当前 VPN 页面。等待期间重新读取所选浏览器的窗口/标签列表和页面状态，最多等待 10 秒。发现新窗口后，切换或绑定该窗口中的资源页面，不要继续在原 VPN 页面寻找资源。
   - 在新窗口的资源页面中确认资源列表已加载，再找到并点击可见的“CNKI 中国知网”模块。随后等待该模块打开的知网页面或标签，并从页面本身实际提供的链接继续操作；不要直达代理子域、猜测路由或复用旧选择器。
   - 每次点击后都检查页面、标签及 URL 是否有变化。若按钮点击后没有新页面，先重新观察一次；最多再尝试一次。连续两次仍无进展就停止操作、保留当前页面并报告阻碍，不要循环重试。
   - 进入候选知网页面后，确认页面确为知网，并检查是否返回 VPN 登录页、出现连接错误或要求重新认证。可访问知网检索页只证明页面可达；仍须单独核验机构认证。
6. 检查页面的“机构登录/组织登录”、机构名称（河南师范大学或经页面证实的相应机构）、机构认证成功提示等。个人账号头像不等于机构认证。认证状态不明或要求付费时，不购买：让用户通过页面提供的机构入口完成认证；单篇无授权应记录为该文献权限不足，不能直接断言整个 VPN 已断开。
7. 在任务内保留访问状态：`insecure_content`（verified_allowed/user_confirmed/blocked/unknown）、实际规则、`vpn_client`（connected/not_running/unknown）、`campus_page`（reachable/login_required/unreachable）、`institution`（verified/required/unknown）、检查时间、观察到的机构名称。权限已核实或用户确认完成后才开始检索/下载；机构权限步骤还须机构已核验。状态不写密码、Cookie、票据或完整登录重定向 URL。

未连接或无法访问时，使用以下提示并等待用户完成：

> 请登录 https://www.htu.edu.cn/info/2011/0116/c18431a250850/page.htm，下载深信服 VPN（EasyConnect），输入 https://vpn.htu.edu.cn，使用学生账号和密码登录。完成后告诉我，我会重新检查连接和知网机构认证。

## 运行中恢复

- 任何时候出现未认证、重新登录、验证码、滑块或人机验证，立即停止该页面的检索/下载重试，说明所处页面和需要用户完成的动作。保留检索条件、已完成文献和当前下载状态。
- 用户完成后重新读取页面，检查机构认证及原检索条件。POST 产生的结果页可能在刷新后丢失检索；用已保存的条件恢复，不猜测查询参数。
- 下载正在进行时先检查对应下载任务，避免登录恢复后重复启动同一文件。
- 每次跨页面、新标签、导出或下载跳转都检查是否仍沿授权路线。使用实际观察到的地址；不得把 `https://kns.cnki.net/dm8/API/GetExport` 等直连接口硬编码到代理页面。
- 优先点击界面原生导出控件。只有运行时明确允许且接口来自当前页面/其已观察到的请求时，才使用该环境允许的调用方式；不复用另一个学校的代理路径。
- 未核验的跨域跳转不是自动允许列表。Chrome 下载权限只针对任务实际观察到且确认属于校园知网流程的来源站点设置。

没有人工认证条件时返回已完成结果及阻碍。此技能不能保证所有校园订阅都覆盖目标文献。
